how to install.

extract all files to a folder

run the executable 

or do the following

download python from official sources or the microsoft store.

install it and when asked add python to path (important)

do the following once only in a cmd or powershell prompt:-

python -m ensurepip --default-pip

python -m pip install PyQt6

python -m pip install psutil


to run the software right click in its folder and open in terminal

input :-

python .\main.py
